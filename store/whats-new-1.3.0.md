# Anystring 1.3.0 — What’s New

Copy into App Store Connect and Google Play (500-character “What’s new” / release notes),
and the longer post for social / Telegram.

## Announcement (Russian)

```
Всем привет!
Новая версия приложения тут.

Эталонный тон теперь свой у каждого инструмента. Гитара, бас и укулеле звучат щипком и быстро затихают. Скрипка, альт, виолончель и контрабас тянут ноту, как смычок. Если быстро переключать ноты, предыдущая не обрывается щелчком, а мягко уступает следующей. Сама нота остаётся ровно той, что написана.

Это Anystring 1.3.0.
```

## Announcement (English)

```
Hi everyone!
A new version of the app is here.

Each instrument now has its own reference tone. Guitar, bass, and ukulele sound plucked and fade quickly. Violin, viola, cello, and double bass hold the note like a bow. Switching notes quickly no longer cuts the previous one with a click; it gives way to the next. The tone stays on the written note.

This is Anystring 1.3.0.
```
