# Anystring 1.4.0 — What’s New

Copy into App Store Connect and Google Play (500-character “What’s new” / release notes),
and the longer post for social / Telegram. Listening starts on open, a string
keeps its check, and the bass low string is easier to hear.

## Announcement (Russian)

```
Всем привет!
Новая версия приложения тут.

Тюнер начинает слушать сам, как только вы его открываете. Stop выключает микрофон, пока вы сами не нажмёте Start. Когда струна попадает в строй, на ней остаётся галочка и один раз коротко вибрирует телефон. Галочка не пропадает, если струна потом снова расстроилась. Смена строя галочки снимает.

Нижнюю струну баса слышно лучше: тихую ноту тюнер больше не отбрасывает.

Это Anystring 1.4.0.
```

## Announcement (English)

```
Hi everyone!
A new version of the app is here.

The tuner starts listening as soon as you open it. Stop keeps the microphone off until you press Start. When a string reaches in tune, it keeps a check and the phone vibrates once. The check stays if the string later goes out of tune. Changing the tuning clears the checks.

The bass low string is easier to hear: a quiet note is no longer thrown away.

This is Anystring 1.4.0.
```
